Names Miner

Find tagged clients in your contacts and message them

1 · Load contacts

Drop contacts files here: .vcf (vCard) or .csv from Google, Yahoo, Outlook, iPhone/Mac or Thunderbird. You can add several at once.

Phone: Contacts › ☰ › Manage contacts › Import or export › Export, then copy the .vcf to this computer. Or export from contacts.google.com.

2 · Find clients

3 · Message

4 · Send via WhatsApp

Load a contacts file to begin.

Each chat opens with your message typed. Press Send in WhatsApp, come back, then press Open next chat (or the N key). After each block the button locks for the set minutes and a notification tells you when the next block is ready. The same message is never opened twice for the same number, and anyone marked Opted out is never messaged again.

WhatsApp doesn't tell other apps about ticks. After sending, set each client's status from what WhatsApp shows (✓ sent, ✓✓ delivered, blue ✓✓ read, a reply, or "not on WhatsApp"). The report uses those marks.
